# A* Pathfinding Demo (Unity)

A simple Unity project demonstrating a grid-based A* (A-Star) pathfinding algorithm implemented in C#.

## Requirements
- Unity 2021 LTS or newer

## How to Run
1. Open the project in Unity
2. Open `Assets/Scenes/AStar_Demo.unity`
3. Press Play

## Features
- Grid-based A* pathfinding
- 4-way and 8-way movement
- Visual path rendering
- Mouse-based tile interaction
